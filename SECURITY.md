# Security Policy

## Supported Versions

Only the most recent release of kotaml, including kotaml-json, is supported with security fixes. Older versions are not supported.

## Reporting a Vulnerability

If you discover or suspect you have discovered a vulnerability, please report it through [GitHub's private vulnerability reporting tool](https://github.com/Heapy/kotaml/security/advisories/new).
Please include the affected version, a short description of the issue, and steps on how to reproduce it. Please do not report vulnerabilities in public issues.

Reports will be assessed privately. For confirmed vulnerabilities, we will coordinate disclosure with the reporter and aim to provide a fix before public disclosure.

Reporters will be acknowledged in the release notes and security advisory with their consent.
